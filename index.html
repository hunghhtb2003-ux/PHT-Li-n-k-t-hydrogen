💡 Ghi nhớ nhanh kiến thức trọng tâm
  • Liên kết hydrogen: Liên kết yếu hình thành giữa nguyên tử H linh động (đã liên kết với F, O, N có độ âm điện lớn) với nguyên tử F, O, N khác có cặp electron hóa trị chưa liên kết.
  • Ảnh hưởng tới tính chất vật lý: Làm tăng đáng kể nhiệt độ nóng chảy, nhiệt độ sôi của các hợp chất như H₂O, HF, NH₃ so với các chất tương đồng.
  • Tương tác van der Waals: Là lực hút tĩnh điện yếu giữa các phân tử do các lưỡng cực tạm thời và lưỡng cực cảm ứng, tăng theo khối lượng phân tử (số lượng electron).

🔗 Google Apps Script Web App Endpoint đã được kết nối tự động. Khi học sinh bấm nộp bài, toàn bộ dữ liệu gồm: Thời gian nộp, Họ tên, Lớp, Điểm tổng, Số câu đúng/sai, Thời lượng làm bài sẽ được gửi đến Google Sheets.

💡 Mã nguồn Google Apps Script mẫu trong Google Sheet (nếu cần tham khảo):

function doPost(e) {
  try {
    var data = JSON.parse(e.postData.contents);
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    if (sheet.getLastRow() === 0) {
      sheet.appendRow(["Thời gian", "Họ tên", "Lớp", "Điểm số", "Điểm tối đa", "Đúng", "Sai", "Chưa làm", "Thời lượng", "Chi tiết bài làm"]);
    }
    sheet.appendRow([
      data.timestamp,
      data.studentName,
      data.studentClass,
      data.totalScore,
      data.maxScore,
      data.correctCount,
      data.wrongCount,
      data.unansweredCount,
      data.duration,
      JSON.stringify(data.details || {})
    ]);
    return ContentService.createTextOutput(JSON.stringify({status: "success"}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch(err) {
    return ContentService.createTextOutput(JSON.stringify({status: "error", message: err.toString()}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
